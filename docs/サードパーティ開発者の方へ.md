# 致第三方开发者

## 第三方使用时的注意事项

### 关于 VOICEVOX 的基本动作

VOICEVOX 应用程序大致由用户可见的 GUI（前端部分）和负责语音合成的引擎（后端部分）构成。通常，当 VOICEVOX 的 GUI 启动时，引擎会（按注册为多引擎的数量）以不可见的方式依次启动。第三方若要使用语音合成功能，需要访问后台启动的引擎。

### 关于对 VOICEVOX 的访问

要使用 VOICEVOX 的引擎，需要使用 API。除非有特殊理由，否则请避免通过 API 以外的方式进行访问。（例如，直接改写文件等操作不仅容易引发故障，还可能导致 VOICEVOX 在事前测试中未经确认的非预期行为。）

基本上，VOICEVOX 已准备了语音合成所需的 API，但如果存在 API 无法实现的功能/操作，建议在 VOICEVOX 的 Issue 页面提出 API 实现提案。

### 关于 API 的访问地址

可通过 HTTP 访问 API。

- VOICEVOX 引擎默认使用的端口号在内部已确定（例：50021/tcp）。
- 若其他应用程序使用了相同的端口号，会因冲突而开启其他端口。
- 最终开启的端口号请参照信息文件进行确认。
- 动态变更端口号是 VOICEVOX v0.16 以后版本的功能。

### 关于运行时信息文件（以下简称信息文件）

为了让第三方能够获取所需信息，系统会生成一个“信息文件”。第三方制作者请首先参照此文件来决定访问地址。

此外，当 VOICEVOX 内部引擎重启时，通信端口号可能会发生变化。当第三方在 API 使用过程中突然发生通信失败时，请确认此文件是否已更新。

（需要注意的是，旧版 VOICEVOX 并未实现此文件生成功能。此外，也存在不动态决定端口号的版本。为保持向下兼容性，请也考虑此文件不存在的情况。）

## 关于信息文件

### 文件位置

文件位于以下位置：

| OS      | 文件路径                                                                 |
| ------- | ------------------------------------------------------------------------ |
| Windows | C:\Users\（用户名）\AppData\Roaming\voicevox\runtime-info.json           |
| MacOS   | /Users/（用户名）/Library/Application Support/voicevox/runtime-info.json |

此外，根据 Windows 的配置文件设置，上述文件的位置可能会发生变化。要准确确定位置，请使用环境变量 `APPDATA` 来定位 Roaming 文件夹。

### 文件内容与含义

文件本身为 JSON 格式。结构如下所示：

```JSONC
{
  //[string] VOICEVOX 的版本号
  "appVersion": "xxx.yyy.zzz",

  //[number] 文件结构版本（每次规格变更时递增）
  "formatVersion": 1,

  //引擎数据（数量与已启动的引擎数相同）
  "engineInfos": [
    {
      //[string] 引擎通称
      "name": "engine1",

      //[string] API 端点
      "url": "http://127.0.0.1:50021",

      //[UUID] 引擎识别用 UUID
      "uuid": "00000000-0000-0000-0000-000000000001",
    },
    {
      "name": "engine2",
      "url": "http://127.0.0.1:50121",
      "uuid": "00000000-0000-0000-0000-000000000002",
    },
  ]
}
```

### 生成时机

- 文件在引擎启动（或重启）时生成、更新。
- 若因某些原因无法获取文件写入权限，则不会更新（例如在更新时其他工具正打开该文件等情况）。
- 此生成时机是基于文件版本 1 的实现，可能在开发过程中发生变化。
