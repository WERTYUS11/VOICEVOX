# 关于颜色

由于存在深色主题，因此需要确保在深色主题下也能良好显示。

## 颜色变量及其作用

### 主题中可指定的颜色

| 变量名              | 作用                             |
| ------------------- | -------------------------------- |
| primary             | 主色                             |
| display             | 用于显示信息的颜色。如文字颜色等 |
| display-on-primary  | 用于在主色上显示信息的颜色       |
| display-hyperlink   | 用于显示链接的颜色               |
| background          | 背景色                           |
| surface             | 比背景色稍显突显的颜色           |
| warning             | 用于警告的颜色                   |
| text-splitter-hover | 分割读音部分的颜色               |
| active-point-focus  | 选中的重音短语的颜色             |
| active-point-hover  | 悬停中的重音短语的颜色           |

### 根据模式变化的颜色

工具栏和分隔线的颜色，在浅色模式下使用 primary，在深色主题下使用 surface。

| 变量名                 | 作用                           |
| ---------------------- | ------------------------------ |
| toolbar                | 工具栏的颜色                   |
| toolbar-button         | 工具栏上按钮的颜色             |
| toolbar-button-display | 工具栏按钮上用于显示信息的颜色 |
| splitter               | 分隔线的颜色                   |
