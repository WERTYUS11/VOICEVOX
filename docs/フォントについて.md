# 字体的制作方法

VOICEVOX 使用经过修改的 Rounded M+ 1p 字体。
具体进行了以下操作：

- 删除提示信息（Hinting）
- 从 ttf 转换为 woff2

## 步骤

1. 从 [自家製 Rounded M+ とは](http://jikasei.me/font/rounded-mplus/about.html) 下载 Rounded M+。
2. 安装 [ttfautohint](https://freetype.org/ttfautohint/)。[^longnote]
3. 构建 [woff2](https://github.com/google/woff2)。
4. 将 `rounded-mplus-20150529.7z` 中的 `rounded-mplus-1p-（字重）.ttf` 全部解压到 `src/fonts`。
5. 使用 ttfautohint 删除 Rounded M+ 的提示信息。名称设为 `Unhinted Rounded M+ 1p`。
6. 使用 woff2 将 ttf 转换为 woff2。

[#1103](https://github.com/VOICEVOX/voicevox/pull/1103) 的创建中使用了以下脚本（PowerShell 7.3.1）：

```pwsh
# cwd：src/fonts
foreach ($f in gci("./*.ttf")){
  py -m ttfautohint -dF " Unhinted" $f.name "unhinted-$($f.name)"
  woff2_compress.exe "unhinted-$($f.name)"
}
```

[^longnote]: 使用了 [ttfautohint-py](https://pypi.org/project/ttfautohint-py/)。
