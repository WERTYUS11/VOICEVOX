# 详细设计方针

## Vuex 与对话框

将对话框视为外部 API，允许从 Vuex Store 的 Action 内部调用。
这是因为可以方便地将对话框前后的行为写在同一个 Action 中，取决于对话框的结果。
虽然某些类型的对话框可能直接作用于 View 并显示对话框 UI，但这也被允许。

## 监听 Vuex state 中的 Map 或数组时

对于元素数量可能较多的 Map 或数组，出于性能考虑，前提是监听实例本身。
更新时请务必替换为新实例。

## EngineId、SpeakerId、StyleId

EngineId 是引擎持有的 ID，在全局范围内唯一且不可变。
SpeakerId 是说话者持有的 ID，在全局范围内唯一且不可变。在不同引擎间也保持相同的 ID。
StyleId 是每个风格持有的 ID，只需在每个引擎内唯一即可。

目标是实现“要唯一确定一种声音，需要 (EngineId, SpeakerId, StyleId) 三者的组合”这一规格。
目前，由于语音合成 API 没有 SpeakerId 参数，因此声音由 (EngineId, StyleId) 两者组合唯一确定。
目前 StyleId 只需在每个引擎内唯一，但目标规格是只需在每个说话者内唯一即可。

由于历史原因，VOICEVOX 中有时会将 SpeakerId 和 StyleId 混淆。
尤其是类型为整数值的 SpeakerId 有时会与 StyleId 混淆。
（例如，将 StyleId 传递给引擎 API 的 SpeakerId 参数等。）

StyleId 目前为整数值类型，但未来计划改为 Uuid。

## 单文件组件（SFC、`.vue` 文件）中 template、script、style 的顺序

请按 `<template>`、`<script>`、`<style>` 的顺序书写。

## 错误处理（实验性运用中）

基本策略是在函数侧抛出异常，在 UI 侧捕获并显示错误对话框。
当抛出可能显示给用户的异常时，请使用 `DisplayableError`，并编写用户友好的消息。

## Zod 的 Schema 与类型定义

Zod schema（`z.object`）的变量名请使用 `[camelCase 名称]Schema`，类型定义（`z.infer`）的名称请使用 `[PascalCase 名称]Type`。

```ts
export const hogeFugaSchema = z.object({
  hoge: z.string(),
  fuga: z.number(),
});

export type HogeFugaType = z.infer<typeof hogeFugaSchema>;
```

## 多引擎

添加引擎的方式有安装 VVPP 文件的形式，以及指定引擎目录路径的形式。

|                        | VVPP                        | 路径                            |
| ---------------------- | --------------------------- | ------------------------------- |
| `EngineInfo` 的 `type` | `"vvpp"`                    | `"path"`                        |
| 添加时的处理           | 将 zip 文件解压到指定文件夹 | 将引擎路径保存到 `config.json`  |
| 读取时的处理           | 读取指定文件夹内的内容      | 读取 `config.json` 中保存的路径 |
| 删除时的处理           | 删除指定文件夹内的目录      | 从 `config.json` 中删除路径     |

## 默认引擎的更新信息

以 json 格式管理默认引擎的更新信息。
更新信息中包含最新包（VVPP・VVPPP 文件）的 URL 和版本等。
包信息按 OS、架构、设备进行分类。

文件格式如下：

```JSONC
{
  //[number] 文件结构版本（每次规格变更时递增）
  "formatVersion": 1,

  // Windows 的信息
  "windows": {
    "x64": {
      "CPU": {
        //[string] 版本
        "version": "x.x.x",

        // vvpp 或 vvppp 的信息
        "packages": [
          {
            //[string] 下载 URL
            "url": "https://example.com/example.vvpp",

            //[string] 文件名
            "name": "example.vvpp",

            //[number] 字节数
            "size": 123456,

            //[string(Optional)] 哈希值
            "hash": "xxxxxxx",
          },
          //...
        ]
      },
      "GPU/CPU": { /* 同上 */ }
    }
  },

  "macos": {
    "x64": {
      "CPU": { /* 同上 */ }
    },
    "arm64": {
      "CPU": { /* 同上 */ }
    }
  },

  "linux": {
    "x64": {
      "CPU": { /* 同上 */ },
      "GPU/CPU": { /* 同上 */ }
    }
  }
}
```
